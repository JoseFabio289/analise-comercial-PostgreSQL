# Análise Comercial com pandas e PostgreSQL

Projeto de análise de dados comerciais desenvolvido com Python, Pandas e PostgreSQL.

O objetivo é simular um fluxo de trabalho de análise de dados, partindo de uma base de vendas bruta até a limpeza, armazenamento em banco de dados e geração de análise e insights de negócio.

## Objetivos da análise

O projeto busca responder perguntas como:

- Quais produtos apresentam maior e menor faturamento?
- Como o desempenho muda entre faturamento e quantidade vendida?
- Como as vendas evoluem ao longo do tempo?
- Quais regiões apresentam melhor desempenho comercial?
- Qual é a relação entre descontos e desempenho nas vendas?
